# inStore Dashboard (User Interface)

This dashboard provides a chat interface to interact with the data placement framework, specifically the intent manager.

## Pre-requisites
- React
- Vite
- TypeScript
- ChakraUI

## How to run 


You need to install node and npm first, then you can run this command from the `ui` directory:
```
npm i
```

then create a .env file that contains the intent manager url (see .env-example) before running a development version:
```
npm run dev
```
